القرارات اللي بتتاخد في كل مشكلة

  • الصفوف المكررةتوحيد الحروف والمسافات الأول، وبعدين drop_duplicates، فالتكرار المخفي بيتلقط.
  • القيم الناقصةكل الأشكال (N/A، -، null، NaN، فاضي) بتتحول لقيمة ناقصة موحدة. السعر بيتعبّى بالـ median ومعاه علامة، والمدينة بتبقى Unknown.
  • التواريخقراءة كل الصيغ وتحويلها لـ YYYY-MM-DD، وأي تاريخ مش مفهوم بيتعلّم للمراجعة.
  • السعرشيل EGP والفواصل وتحويله لرقم float.
  • الكمياتالصفر والسالب بيتحولوا لقيمة ناقصة مع علامة، والقيم الشاذة بتتعلّم بطريقة IQR بدل ما تتمسح.
  • أنواع البياناتتثبيت نوع كل عمود (int, float, datetime, string) في آخر خطوة والتأكد منه.

الكود

import pandas as pd, numpy as np

df = pd.read_csv("orders.csv", dtype=str)

# 1) توحيد القيم الناقصة بكل أشكالها
na_values = ["", "n/a", "na", "-", "nan", "null", "none"]
df = df.apply(lambda s: s.str.strip())
df = df.apply(lambda s: s.mask(s.str.lower().isin(na_values)))

# 2) توحيد الأسماء والمدن (حروف + مسافات)
for col in ["customer", "city"]:
    df[col] = (df[col].str.replace(r"\s+", " ", regex=True)
                      .str.strip().str.title())
df["city"] = df["city"].fillna("Unknown")

# 3) حذف المكرر بعد التوحيد
before = len(df)
df = df.drop_duplicates(subset=["customer", "city", "date", "price", "qty"])
print("duplicates removed:", before - len(df))

# 4) التواريخ -> YYYY-MM-DD
df["date"] = pd.to_datetime(df["date"], format="mixed", dayfirst=True, errors="coerce")

# 5) السعر -> رقم
df["price"] = pd.to_numeric(
    df["price"].str.replace("EGP", "", case=False).str.replace(",", ""),
    errors="coerce")
df["price_imputed"] = df["price"].isna()
df["price"] = df["price"].fillna(df["price"].median())

# 6) الكميات غير المنطقية
df["qty"] = pd.to_numeric(df["qty"], errors="coerce")
df["invalid_qty"] = df["qty"] <= 0
df.loc[df["invalid_qty"], "qty"] = np.nan
q1, q3 = df["qty"].quantile([.25, .75])
df["qty_outlier"] = df["qty"] > q3 + 1.5 * (q3 - q1)

# 7) أنواع البيانات النهائية + الحفظ
df = df.astype({"customer": "string", "city": "string", "price": "float"})
df["qty"] = df["qty"].astype("Int64")
df["date"] = df["date"].dt.strftime("%Y-%m-%d")
df.to_csv("orders_clean.csv", index=False)
